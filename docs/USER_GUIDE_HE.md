# מדריך משתמש קצר — WILD Clips

## 1. כניסה

פתחו בדפדפן את [wildclips.tech](https://wildclips.tech) והזדהו בחלון הכניסה. פרטי המשתמש והסיסמה נמסרים בנפרד.

## 2. טעינת תמונות וסרטונים

בחלונית **„המדיה שלך”** גררו קבצים מהמחשב או לחצו לבחירה. אפשר להעלות כמה קבצים יחד; המונה מציג כמה מהם הועלו בהצלחה. הגודל המרבי הוא **50 MB לקובץ**.

הפורמטים הנתמכים:
- **תמונות:** JPG/JPEG, PNG, BMP, WEBP, TIF/TIFF.
- **סרטונים:** MP4, MOV, AVI, MKV, M4V, WEBM, MTS, 3GP.

## 3. צפייה במדיה וזיהוי חיות

- לחצו על תמונה או סרטון בספרייה כדי לראות תצוגה מקדימה.
- לחצו על **„זהה חיות”** כדי להתחיל זיהוי. העיבוד מתבצע בשרת ועשוי להימשך זמן מה.
- בחלונית **„מצאתי חיות”** אפשר לחפש או לסנן לפי מין. לחיצה על זיהוי מציגה את קובץ המדיה ואת הרגע שבו זוהתה החיה; אפשר גם לתקן או למחוק זיהוי.
- בתצוגה המקדימה אפשר ללחוץ **„הוסף זיהוי”** כדי להוסיף זיהוי ידני. בחרו מין מהרשימה או הזינו שם חופשי; בסרטון יש להזין זמן התחלה וסיום. זיהויים ידניים מסומנים כ„ידני”.
- אפשר לסנן את הספרייה לפי תמונות או סרטונים, למיין ולמחוק קבצים.

## 4. יצירת קליפ

1. הוסיפו קובץ לציר הזמן באחת משתי דרכים: בחרו אותו בספרייה ולחצו **„+ הוסף את הנבחר”**, או גררו אותו מהספרייה אל ציר הזמן. חזרו על הפעולה עבור כל קובץ שתרצו לכלול.
2. סדרו את הקטעים בציר הזמן. אפשר לשנות את נקודות ההתחלה והסיום של סרטון ואת משך הצגת התמונה.
3. הגדירו כותרות פתיחה/סיום, כתוביות ומעבר בין קטעים. כדי להוסיף פס קול, סמנו **„הוסף מוזיקה”**, כתבו תיאור (מומלץ באנגלית), בחרו סגנון וכוונו את העוצמה.
4. לחצו **„הפקת סרטון”** והמתינו לסיום. יצירת מוזיקה באורך 30 שניות ארכה כ-2 דקות בבדיקת השרת; ביצירה הראשונה הורדת המודל עשויה להאריך את ההמתנה. התהליך מתבצע ברקע.

## 5. צפייה והורדת תוצרים

עברו ללשונית **„תוצרים”**. כשהסטטוס הוא **„מוכן”**, אפשר לנגן את הקליפ, להוריד אותו או למחוק אותו.
